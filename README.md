# BancontactPro.SDK.Samples.Net

> **Dit is geen officieel project van Bancontact.** Onafhankelijke samples bij de [BancontactPro.SDK](https://github.com/yvebrecht/BancontactPro.SDK)-bibliotheken. Deze repo blijft privé tot er een gepubliceerd pakket is waar het sample op kan bouwen.

Dit sample is verhuisd uit [BancontactPro.Net](https://github.com/yvebrecht/BancontactPro.Net) (`samples/` en `tests/BancontactPro.Net.Sample.Api.Tests`), zonder git-geschiedenis.

## Bouwen

De bibliotheek is nog niet op NuGet gepubliceerd; het sample verwijst daarom naar een zusterfolder: clone `BancontactPro.Net` naast deze repo (`..\BancontactPro.Net`). Zodra v2 is gepubliceerd wordt dit een `PackageReference`.

Zie ook `samples/BancontactPro.Net.Sample.Api/README.md`.
